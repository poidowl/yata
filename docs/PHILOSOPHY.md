# yata — 哲学・設計ブリーフ（プロジェクトチーム差し入れ用）

> **「音声から『かわいくなさ』を多次元的に発見する。それに失敗したら『かわいい』。」**

このドキュメントは、**`poidowl/yata`**（八咫鏡＝音という鏡）が立ち上がるきっかけになった対話の思考ログを、開発チーム（人間・AIエージェント双方）がそのまま設計指針や `AGENTS.md` の背景文脈として参照できるようにまとめたものです。

## 1. 出発点：ニューラル音声合成の「その先」へ

ニューラル音声合成は、大量の録音データから「人間が演じたかわいい声」のテクスチャや抑揚を統計的に再現する点で一定の成果を出している。しかし、それはあくまで**結果の模倣（ブラックボックス）**であり、「なぜかわいいのか」「どこで壊れるのか」を説明も反証もできない。

その先へ踏み込むには、数学の予想を機械検証（Lean など）で定理にしていくのと同じように、**「検証可能なかわいさ」**――公理と反証ループによって探索・発見できる対象として音声を捉え直す必要がある。

## 2. 第0公理と「エラトステネスの篩」構造

言葉が関係をすべて書き切れず、数学が宇宙をすべて書き切れないのと同じように、かわいさも正面から完全定義することはできない。もし100%ルールで閉じ切ってしまえば、それは「予定調和の記号」になって死んでしまう。

そこで `yata` は次の出発点（第0公理）を置く。

- **第0公理**：**「かわいい、全部は、かけない。でも『かわいくない』は書ける。」**
- **検証の定義**：音声から「かわいくなさ」を多次元的に発見し、**すべての検出器が反証に失敗して生き残ったもの**を「かわいい候補（`SURVIVED_KAWAII_CANDIDATE`）」とする。

数論において「素数を一発で書き出す単純な公式はないが、合成数（2の倍数、3の倍数…）をふるい落とせば素数が残る」という**エラトステネスの篩**と、完全に同じ構造である。

## 3. 「音という鏡」と存在論の2段構え

既存の音声工学は「時間に沿って変化する波形・スペクトル・エンベロープ」という枠に縛られがちだが、ヒトが音を聴いて「かわいくない」と弾くとき、実際には**「音という鏡」の向こうに『一緒にいたくないなにか』が映り込んでいること**を身体が反射的に感じ取っている。

したがって、音声評価は2段構えになる。

1. **第1関門：存在の検証（「なにも、いない」vs「なにか、いる」）**
   - 音の背後に「1つの統一された隠れた実体（身体・有限の肺活量・内部状態）」を仮定しないと説明がつかないか。
   - 手がかりは **共通原因（複数チャネルの因果的な連動）**、**時間の矢（履歴依存・不可逆性）**、**有効複雑性（完全周期でも完全雑音でもない揺らぎの臨界帯）**。
2. **第2関門：性質の検証（「一緒にいたくない」の排除）**
   - 「なにか、いる」を越えても、そこに威圧・トゲ・計算・苦しさが映っていれば「怖い／あざとい／かわいくない」になる。
   - 「一緒にいたくない」がすべて消えて、聴き手の身体がふっと力を抜いて「そばにいていいな」と思えた像が「かわいい」。

## 4. 全宇宙の「かわいくない」初版マップ（5領域・11次元）

`yata` の検証器（Falsifiers）が今後カバーしていく「かわいくなさ」の全体地図。

| 領域 | かわいくなさの次元 | 鏡に映っているもの（検出の手がかり） | 落ちる相 |
| :--- | :--- | :--- | :--- |
| **1. 存在の欠如**<br>（なにも、いない） | **無相関の張りボテ** | ピッチ・音圧・息・音色が共通原因なくバラバラに動く | 空っぽ・作り物 |
| | **無記憶（時間の矢なし）** | 直前の発話の勢いや疲労を引き継がない（切り貼り） | 録音・記号 |
| | **完全周期／完全雑音** | 寸分違わず予測できる、または完全に無秩序 | 機械・ただの風 |
| **2. 攻撃性と威圧**<br>（怖い・うるさい） | **エッジの鋭さ** | 立ち上がり・破裂・声門閉鎖が硬く、高域に鋭い角がある | 甲高い・ナッタ化 |
| | **過大スケール** | 共振管が長い・重心が低く「大きい／重い」 | 威圧・いかつい |
| | **遠距離モード** | 呼気圧が高く、空間へ張り上げる発声様式 | 遠い・叫び・放送 |
| **3. 力学の破綻**<br>（苦しい・不気味） | **制御の崩壊** | 制約が強すぎて目標に追いつけず発散・失速する | 苦しそう・病弱 |
| | **物理的不連続** | 慣性を無視した瞬間ワープや不自然なクリック | グリッチ・不気味 |
| **4. 過剰な演技**<br>（あざとい・嘘） | **型の硬直** | 「かわいいはずの数値」に張り付いて文脈で揺れない | あざとい・人形 |
| | **因果なき誇張** | 呼気や感情の根拠なく語尾上げや息漏れを盛っている | わざとらしい |
| **5. 関係の断絶**<br>（他人事） | **無指向性** | 聞き手との距離や「間（ま）」の呼吸が噛み合わない | よそよそしい |

## 5. 実験デザイン：リトマス試験紙と 2×2 比較

- **最小リトマス試験紙「鳴る／ナル／鳴った／ナッタ」**
  - 音素記号としては同じ `/n a r u/` と `/n a Q t a/` でも、「柔らかく開いて溶ける（鳴る）」vs「乾いた記号（ナル）」、「丸い促音着地（鳴った）」vs「硬い促音・鋭い破裂（ナッタ）」の違いが明確に分離できること。
- **2×2 の対照比較（人の声／人以外の音 × 一緒にいたい／いたくない）**
  - 「人の声」と「人が作っていない音（自然音・機械音・動物）」を対照比較し、さらに「一緒にいたい／いたくない」を掛け合わせる。
  - 人の声どうしの差から「人間っぽさ」を引き算し、人以外の音どうしの差から「言葉の意味」を引き算することで、普遍的な「一緒にいたい音」の核を抽出する。

## 6. 開発・運用の原則

1. **LLMフレンドリーがあるべき姿**
   - 波形そのままではなく、どの次元で何が映ったか・2音の差分（`--compare`）は何かをコンパクトな構造化テキスト／JSONで出力し、LLMが自律的に推論・反例分析・パラメータ探索を回せる「目」として機能させる。
2. **反例は失敗ではなく「新しい次元の発見」**
   - すべての検出器をすり抜けたのに耳で聴いて「一緒にいたくない」音が見つかったら、それは「まだ名前がついていない新しい『かわいくなさ』の次元」が見つかった収穫。検証器を1本追加して篩を細かくする。
3. **回るループと航海の心構え**
   - **哲学 → アイデア → コード → 実音で反例発見 → 哲学の更新** というループを回し続ける。
   - 「カヌーで大西洋よりでかい海を渡る」ような挑戦だが、かわいい大陸に着く前に「『なにか、いる』が立ち上がる音の法則」など別の面白い新大陸に流れ着くことも大歓迎とする。
